# Agenda 08 – Login, Session e CRUD de Amigos em PHP

## 📖 Sobre o Projeto

Este projeto foi desenvolvido para a **Agenda 08 da disciplina de Programação Web II**, com o objetivo de aplicar conceitos de autenticação, controle de acesso e manipulação de dados utilizando **PHP** e **MySQL**.

A aplicação permite que usuários autenticados realizem operações de cadastro e gerenciamento de contatos através de uma interface web simples e funcional.

---

## 🚀 Funcionalidades

- ✅ Login de usuário
- ✅ Validação de credenciais no banco de dados
- ✅ Controle de acesso utilizando Session
- ✅ Bloqueio de acesso direto por URL
- ✅ Cadastro de amigos
- ✅ Listagem de amigos
- ✅ Edição de registros
- ✅ Exclusão de registros
- ✅ Logout seguro
- ✅ Reutilização de código com arquivos compartilhados

---

## 🛠 Tecnologias Utilizadas

- PHP
- MySQL
- MySQL Workbench
- Apache (XAMPP)
- HTML5
- CSS3
- Visual Studio Code
